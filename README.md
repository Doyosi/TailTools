# TailTools

Native JavaScript UI plugins for Tailwind CSS v4 and Laravel Blade.

```powershell
npm ci
npm test
npm run build
npm run test:package
npm run dev
```

This repository builds a private local tailtools@0.0.0 archive; this maintenance does not publish it. See [installation](docs/installing.md), [development](docs/developing.md), [tests](tests/README.md) and [REPORTS.md](REPORTS.md).
