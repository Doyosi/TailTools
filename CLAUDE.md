# Claude Code Instructions for TailTools

Adhere to the repository guidelines in `AGENTS.md`:
- Every new plugin is named `CGE<X>` in `plugins/CGE<X>/` (`CGE<X>.js`, `CGE<X>.d.ts`, `style.css`, `index.js`).
- Plan must be written to `ai-todos/plans/CGE<X>-plan.md`.
- Phase checklist must be written to `ai-todos/todo-cheks/CGE<X>-checklist.md`.
- Always test at the end of creation using `index.html`.
- Create complete documentation in `docs/CGE<X>/` (`README.md`, `usage.md`, `examples.md`, `api.md`).
- Generate universal AI skills in `.agents/skills/cge-<x>/SKILL.md`.
- Ensure dual compatibility: Tailwind CSS v4.3+ and Laravel (Blade & Vite).
- Author in clean Native JavaScript with complete TypeScript declaration files.
